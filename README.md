# Inter-Exchange Arbitrage

Сервер на Go для сбора и обработки рыночных данных с криптовалютных бирж. Приложение получает сведения о рынках, сопоставляет торговые пары и доступные направления перевода, подписывается на потоки стаканов и публикует снимки рынка.

> Проект предназначен для мониторинга и анализа данных. Он не выполняет автоматическую торговлю.

## Возможности

- адаптеры бирж с REST API и WebSocket;
- сбор сведений о спотовых и фьючерсных рынках;
- поиск совпадений между биржами с учётом доступности рынков и сетей перевода;
- динамическое обновление подписок на стаканы;
- параллельный запуск сборщиков данных;
- чтение конфигурации из `.env`;
- поддержка списка WebSocket-прокси через `proxies.txt`;
- периодическая публикация снимков стаканов (если задан `MARKET_SNAPSHOT_URL`);
- корректное завершение по сигналам ОС.

Подключение **11 бирж** реализовано в адаптерах: Binance, BingX, Bitget, BitMart, Bybit, CoinEx, Gate.io, KuCoin, MEXC, OKX и XT.

## Технологии

Go, REST API, WebSocket, gorilla/websocket, Protocol Buffers, Zap.

## Архитектура

- `cmd/bot` — сбор конфигурации и запуск приложения;
- `internal/exchange` — общий контракт адаптера и реализации для бирж;
- `internal/engine` — координация сборщиков, сопоставление рынков и работа со стаканами;
- `internal/cmc` — данные и снимок CoinMarketCap;
- `internal/core` — конфигурация, доменные типы и общие компоненты.

## Конфигурация и запуск

Нужен Go 1.26+.

1. Склонируйте репозиторий и создайте `.env` на основе `.env.example`.
2. Укажите биржи в `EXCHANGES` и настройте переменные для нужных адаптеров. API-ключи заполняйте только если они требуются выбранной конфигурацией.
3. При необходимости добавьте адреса прокси в `proxies.txt` — по одному адресу на строку.
4. Запустите сервер:

```bash
go run ./cmd/bot
```

Параметр `MARKET_SNAPSHOT_URL` задаёт адрес получателя снимков рынка; при его отсутствии отправка снимков не включается. Подробный перечень поддерживаемых переменных находится в `.env.example`.

## Масштаб и производительность

По сообщению автора, в ходе проверки проект поддерживал около **7 000 WebSocket-подключений**, а снимки рынка обновлялись каждые **5 секунд**. Результат относится к конкретному запуску и конфигурации; условия замера не приводятся.

## Статус

Личный проект в разработке. Функциональность и доступность API бирж зависят от текущих ограничений их публичных интерфейсов.
